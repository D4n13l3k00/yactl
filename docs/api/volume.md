# Громкость

`volume.backend` по умолчанию `off`; доступны `simulate` и `alsa`. Смена требует
перезапуска API. `daemon-reload` отклоняет её без изменения активной конфигурации.

## Запросы и CLI

`GET /v1/volume` требует `read`: возвращает кэшированные стереозначения, линейные
проценты, возраст и готовность. `POST /v1/volume` требует `hardware`:

```json
{"percent":50}
{"percent":10,"lease_ms":1000}
```

Процент — целое число 0..100, необязательный срок — 100..5000 мс. Лишние поля,
неконечные числа и неверный JSON отклоняются.

```sh
yactl volume status
yactl volume set 50
yactl volume set 10 --lease-ms 1000
yactl --json volume status
```

CLI использует тот же версионированный Unix API.

## Временное изменение

Постоянное значение действует до другой записи. Временное восстанавливает исходные
левый и правый каналы по истечении срока или при штатной остановке, только если
микшер ещё совпадает с нашей последней записью. Продление сохраняет исходную базу,
пока состояние остаётся нашим. Новая постоянная запись отменяет старое временное
восстановление. Более новые значения прошивки или сторонних клиентов сохраняются.

Это линейная шкала ALSA, а не воспринимаемая громкость и не калиброванные дБ.
Пересчёт округляет к ближайшему уровню 0..255: 50% даёт 128. Чтение возвращает
фактический квантованный процент и оба канала. Установка выравнивает их, но
восстановление сохраняет исходное индивидуальное значение каждого. Mute не
объявляется: ноль означает минимальный уровень микшера.

## Выполнение и аппаратный интерфейс

Отдельный поток обслуживает очередь из восьми команд и опрос. Отменённые или
просроченные команды пропускаются до ввода-вывода. HTTP-тайм-аут не отменяет
начатую запись; потерявший ответ клиент должен перечитать состояние.
Опрос выполняется раз в секунду, срок временного изменения проверяется при
каждой итерации. Через три секунды без свежего чтения значение недоступно.
Остановка ждёт до 500 мс. SIGKILL, потеря питания и зависшее ядро не гарантируют восстановление.

Адаптер независимо проверяет Cucumber по device-tree, без доверия к ручному
указанию модели. Принимается AML-AUGESOUND, `Master Playback Volume`, два
целочисленных канала с чтением/записью, пределами 0..255 и единичным/переменным
шагом. Числовой control ID разрешается по имени. Клиенты прошивки не блокируются.

Используется [Linux ALSA control UAPI](https://github.com/torvalds/linux/blob/v5.4/include/uapi/sound/asound.h),
без libasound и внешнего amixer. Независимая проверка C-заголовков дала размеры
ID/info/value/card 64/272/1224/376 байт и смещения union info/value 80/72 для LP64.
Rust-проверки времени компиляции и размеры ioctl закрепляют ABI. На AArch64
проверены чтение и точная запись того же значения без изменения наблюдаемого
уровня. Привязки аппаратного интерфейса реализованы в проекте.
