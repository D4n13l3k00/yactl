# Датчики

Один отдельный поток опрашивает датчики и обновляет ограниченный кэш. HTTP-обработчики
не открывают аппаратные файлы и не создают блокирующую операцию на каждый запрос.
`sensors.backend` принимает `off`, `simulate`, `sysfs`; по умолчанию `off`.
Смена реализации требует перезапуска API.

## Единицы измерения

[ABI IIO Linux 5.4](https://github.com/torvalds/linux/blob/v5.4/Documentation/ABI/testing/sysfs-bus-iio)
различает интенсивность и освещённость. Vendor-атрибут `in_intensity_input`
возвращается как сырые отсчёты, а не люксы. Люксы допустимы только для проверенного
обработанного атрибута освещённости. Каналы ADC остаются сырыми отсчётами
напряжения до подтверждения физического пересчёта.

[`temp` термозоны](https://kernel.org/doc/html/v5.7/driver-api/thermal/sysfs-api.html)
измеряется в тысячных градуса Цельсия. Деление на 1000 применяется всегда,
включая отрицательные и близкие к нулю значения. Порог величины числа не служит
определителем единиц. Используются термозоны, а не произвольные hwmon-атрибуты,
для которых существуют исключения с термисторами напряжения.

## API и обнаружение

`GET /v1/sensors` и `GET /v1/sensors/{id}` требуют `read`. Идентификатор ищется
в реестре и никогда не трактуется как путь. Ответ сообщает тип, единицы,
поддержку, готовность, значение и возраст. Некорректное, недоступное или устаревшее
показание не имеет текущего значения. Запись, изменение усиления и времени
интеграции не предоставляются.

Распознаются термозоны с корректными type/temp, `ltr308als01` и сырые каналы
`meson-c2-saradc`. Неизвестные IIO-драйверы не объявляются. Температура ограничена
диапазоном −273,15..1000 °C; сырые отсчёты — unsigned 32-bit; обработанная
освещённость должна быть конечной и неотрицательной. При каждом опросе проверяется
идентичность драйвера/типа, чтобы повторное использование индекса не оставило
старые подписи и единицы. Обнаружение выполняется при запуске. Hotplug и смена
идентичности требуют перезапуска для нового обнаружения.

## Ограничения

Опрос — раз в секунду, не более 16 датчиков, 128 записей каталога при обнаружении
и 128 байт на атрибут. Возможность объявляется после корректного первого чтения.
Поддержка и текущая готовность различаются. Через три секунды показание считается
устаревшим; значение при ошибке или устаревании — null. Локальные идентификаторы
могут измениться при переупорядочении устройств. Достижение лимита обнаружения
отмечается в состоянии адаптера.

Ввод-вывод только для чтения и вне Tokio. Зависшее чтение задерживает остальные
датчики этого потока, но не создаёт новые потоки и не мешает API пометить кэш
устаревшим. Остановка ждёт не более 500 мс; блокирующий вызов не считается
отменённым. Проверки используют симуляцию и временный sysfs. Обнаружение и опрос
на колонке подтверждены [испытаниями](../development/verification.md); перенос приложений остаётся отдельной работой.
