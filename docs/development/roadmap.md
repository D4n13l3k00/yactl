# Дальнейшая работа

## Реализовано

Менеджер сервисов и отдельный API-процесс, версионированные настройки,
транзакционный reload, идентификация, разрешения HTTP и приватный Unix API.
Аппаратные адаптеры RGB, часов, датчиков, ALSA, ввода и событий прошивки
имеют симуляционные проверки. [Проверки на Миди](verification.md) перечислены отдельно.

## Остаётся проверить

- Полную перезагрузку устройства с установленной службой.
- Final-command и события alarmd на подходящей прошивке.
- Изменение слышимой громкости и её временное восстановление на устройстве.

## Планируется

Необязательный веб-интерфейс. Headless-сборка и локальный API должны работать
без него. Новые модели поддерживаются только после проверки их интерфейсов:
совпадение имени модели не включает аппаратную запись.
