# Проверки на Миди

Испытания выполнены на Cucumber DVT2 25 октября 2026 года. Таблица показывает
объём фактической проверки, а не гарантию для всех прошивок.

| Интерфейс | Проверено на устройстве |
| --- | --- |
| RGB | Запись всех 24 пикселей кольца и шести логотипа, независимое чтение BGR, точное штатное восстановление |
| Часы | Кадр 12:34, яркость, чтение 45 сегментов и двух sync-узлов, восстановление |
| Датчики | Обнаружение и опрос с проверкой единиц |
| ALSA | Чтение обоих каналов, точная запись того же значения без изменения слышимого уровня |
| Ввод | Выбор устройств до открытия, начальные снимки, физическое нажатие/отпускание `awinic_sar` |
| Прошивка | Поиск aliced, соединение, обычная речь; готовность только после распознанного сообщения |
| Служба | Запуск, повторный start, restart, готовность API, сохранение SSH и настроек |
| Fish | Команда `yactl` и автодополнение в новой сессии |

Клиент подсветки отправлял кадры без собственных framebuffer-дескрипторов. Штатное освобождение и SIGKILL
клиента восстановили состояние; API и менеджер продолжили работу.

## Установка

Проверены `check` без `--root`, запуск и перезапуск init-скрипта, готовность
аппаратных адаптеров и доступ по SSH. Конфигурация и постоянный ID сохранены.
Корневая файловая система возвращена в режим только для чтения.

## Не подтверждено физически

- Final-command и события alarmd: есть синтетические проверки, но нет нативного подтверждения.
- Изменение слышимой громкости и временное восстановление: проверены симуляцией.
- Полная перезагрузка колонки с установленной службой.
- Предельные задержки и восстановление при произвольной конкуренции прошивки,
  потере питания, SIGKILL API-процесса или зависшем вызове ядра.

Новые артефакты требуют своих проверок. Сырые логи, речь, приватная конфигурация
прошивки и аппаратные снимки в репозиторий не включаются.
