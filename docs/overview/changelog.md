# История изменений

## 0.1.0 — ещё не выпущена

Подготовка первого публичного релиза:

- Менеджер сервисов с политиками перезапуска, остановкой группы процессов,
  постоянными записями и ограниченными логами.
- Приватный сокет администрирования, версионированный API, отдельные разрешения
  HTTP и транзакционное применение настроек.
- Явно включаемые адаптеры RGB, часов, датчиков, громкости, ввода и событий прошивки Миди.
- Отдельный API-процесс и ограниченная аппаратная работа вне менеджера сервисов.
- Статическая сборка AArch64 musl с удалением символов и проверенной упаковкой UPX.

Аппаратные проверки и оставшиеся ограничения описаны в
[README](support.md).
