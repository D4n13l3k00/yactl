## API станции

Версия API указана в пути: `/v1`. Приватный сокет — `<root>/api.sock`, HTTP
по умолчанию слушает `127.0.0.1:8098`. Владелец сокета получает административный
доступ. Для HTTP предусмотрены отдельные разрешения на чтение, оборудование
и сервисы. Перед удалённым подключением прочитайте [настройку](../guide/configuration.md).
