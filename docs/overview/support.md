# Поддержка и ограничения

Первая аппаратная цель — Станция Миди (`cucumber`). Другие модели могут запускать
менеджер сервисов, но их оборудование не считается поддержанным. Ручная настройка
`device.model` не обходит проверки адаптеров.

## Подтверждено на Миди

| Область | Объём проверки |
| --- | --- |
| RGB и часы | Запись, независимое чтение результата, точное штатное восстановление |
| Датчики | Обнаружение и чтение; единицы по ABI |
| Громкость | Чтение и запись того же значения без изменения уровня |
| Ввод | Нажатие/отпускание, выбранные устройства, состояние |
| Прошивка | Обычная речь; подключение и поиск aliced |
| Установка | Запуск и перезапуск init-скрипта, готовность, сохранение SSH |

Final-command и alarmd проверены синтетически, но не подтверждены на физической
прошивке. Изменение слышимой громкости и её временное восстановление также не
испытывались физически. Полная перезагрузка колонки не выполнялась.
[Протокол испытаний](../development/verification.md) содержит хеши и точные границы результатов.

## Зависимость от Quasar

Менеджер, API и прямые адаптеры используют Linux: framebuffer, sysfs, evdev,
ALSA. Для них нужен соответствующий драйвер и права доступа, а не работающий Quasar.
Речь и будильники поступают от aliced/alarmd. Без них yactl продолжит управлять
сервисами и доступным оборудованием, но не будет получать эти события.

## Восстановление ресурсов

Временное владение ограничено сроком, разрыв соединения освобождает ресурс.
Восстановление условное: новое состояние прошивки не должно затираться старым
снимком. Сама прошивка работает вне арбитража yactl. SIGKILL API-процесса,
потеря питания и зависший вызов ядра не гарантируют восстановление; состояние
предыдущего процесса не переживает его смерть.
